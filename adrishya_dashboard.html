Forward Process: Running the Full Adrishya Stack

Follow these 4 steps on your Windows laptop to run real-time webcam redaction, launch the FastAPI dashboard server, and demonstrate forensic restoration during your review.

Step 1: Install FastAPI & Uvicorn in your (venv)
pip install fastapi uvicorn mediapipe cryptography
Step 2: Run Direct OpenCV Redaction Window
python main.py

Opens your webcam, applies Soft/Hard masking, and saves redacted_output.mp4 + recovery_vault.adrishya.

Step 3: Launch FastAPI Server + Web Dashboard
python main.py --mode api --port 8000

Serves this dashboard at http://localhost:8000 and live video at http://localhost:8000/stream.

Step 4: Run Cryptographic Forensic Restoration
python main.py --mode restore

Decrypts SOFT regions using secret.key and writes restored_forensic.mp4.

Viewing on Your Phone (Gemini Chat + Live Dashboard)

1. Why This Chat Didn't Appear in the Phone Gemini App
  • Account Mismatch: Check the profile icon in the top-right of your phone's Gemini app and ensure it's logged into the exact same Google account as your laptop browser.
  • Gemini Apps Activity Off: If Web & App Activity is paused at myactivity.google.com/product/gemini, chats aren't synced across devices.
  • Canvas Side-Panel Chats: The mobile app sometimes hides Canvas file cards; open gemini.google.com in Chrome on your phone (or Pin this chat on desktop) to see the full conversation immediately.
2. Open the Live Adrishya Dashboard on Your Phone Over Wi-Fi

Because main.py --mode api binds to 0.0.0.0:8000, you can control your laptop's redaction system live from your phone during your project demo:

  1. Connect your laptop and phone to the same Wi-Fi / mobile hotspot.
  2. In laptop PowerShell, run ipconfig and copy your IPv4 Address (e.g., 192.168.1.45).
  3. Run python main.py --mode api --port 8000 on your laptop.
  4. On your phone browser, open http://<your-laptop-ip>:8000 to view the live redacted stream and toggle Soft/Hard policies from your phone!
